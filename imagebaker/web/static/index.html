ImageBaker Help & Shortcuts

Comprehensive guide to mouse controls, hotkeys, and dataset synthesis workflows.

🧭 General & Navigation

  • Theme & GridToggle Dark/Light theme and canvas gridlines from top-right header
  • Mouse WheelZoom in/out around cursor
  • Ctrl + Drag / Space + DragPan canvas viewport smoothly
  • [ / ]Switch to Previous / Next image (Layerify) or canvas (Baker)
  • FFit image or composite to viewport

📐 Layerify (Annotation Studio Shortcuts)

  • ERectangle drawing mode
  • WPolygon drawing mode (click 1st vertex, Enter, or Double-Click to finish)
  • QPoint / Keypoint annotation mode
  • BBrush segmentation mask mode (Alt + Wheel adjusts brush size)
  • V / Escape / Right-ClickSelect / Idle mode
  • 0 – 9Quick-select label slot and relabel active selection
  • Click & DragSelect, move annotation, or adjust handles in any mode
  • Arrow KeysNudge selected annotation by 1px (Shift + Arrows = 10px)
  • LLayerify selected annotation(s) into Baker layers
  • PRun AI model prediction on current image / prompt points
  • CEdit caption and class label of selected annotation
  • HToggle visibility of selected annotation
  • Delete / BackspaceDelete selected annotation(s)
  • Ctrl + Z / Ctrl + YUndo / Redo annotation edits
  • Ctrl + C / Ctrl + VCopy / Paste selected annotation
  • Ctrl + ASelect all annotations
  • Double-Click Label PillQuick-edit annotation label and caption notes

🎨 Baker (Compositing & Dataset Synthesis Shortcuts)

  • Ctrl + ClickMulti-select layers (on canvas and in layer list)
  • Arrow KeysMove selected layer(s) (Shift + Arrows = 20px)
  • Ctrl + Up / Down or W / SReorder selected layer Z-order
  • R / Shift + RRotate selected layer (+5° / -5°)
  • Ctrl + GGroup selected layers into a composite layer, or ungroup
  • Ctrl + SSave current keyframe state to timeline
  • Ctrl + NAdd new blank drawable layer
  • Ctrl + D / Ctrl + EToggle Draw / Erase brush mode on selected layer
  • Mouse WheelAdjust brush size in draw/erase mode
  • Delete / BackspaceDelete selected layer(s)
  • Ctrl + C / Ctrl + VCopy / Paste layer
  • Ctrl + Z / Ctrl + YUndo / Redo Baker timeline edits
  • H / CToggle visibility / edit caption for selected layer

💡 Workflow Hints

  • Layerify to BakerUse Layerify for annotating source images, and Baker for composing, augmenting, and synthesizing new states.
  • Layer GroupingGroup related foreground objects to transform and animate them as a unit, then ungroup for sub-element tweaks.
  • Grid AlignmentToggle the dimension-adaptive grid when aligning objects or inspecting pixel borders.
  • Automated ExportUse the Baker export menu to generate YOLO, COCO, or instance segmentation datasets ready for training.
